访问令牌是什么？怎么拿？

这个站是纯静态页面，没有自己的服务器，所以密码不能存在网站里——那样谁都能翻源码看到。 真正管用的办法是让 GitHub 来验证身份：填一个只对这个仓库有写入权限的令牌，就相当于一把钥匙。

推荐用细粒度令牌（Fine-grained）：

  1. 打开 Generate new token
  2. Token name 随便写，比如 {{siteTitle}}-管理
  3. Expiration 按需选择（90 天比较合适）
  4. Repository access → Only select repositories → 勾选 仓库
  5. Permissions → Repository permissions → Contents 设为 Read and write
  6. 点 Generate token，把生成的 github_pat_… 复制过来

令牌只会保存在你自己的浏览器里（localStorage），不会上传到别处。 它会随「退出登录」一起清除。公共电脑上用完记得退出并撤销令牌。
